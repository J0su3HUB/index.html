Unidad 3: Introducción a la programación

Lenguajes · Python · Operadores

En esta unidad conoceremos los fundamentos de la programación. Aprenderemos qué son los lenguajes de programación, cómo se clasifican y daremos los primeros pasos con Python. También estudiaremos los operadores que permiten realizar cálculos, comparaciones y construir condiciones dentro de un programa.

Objetivo: introducirte al pensamiento de programación y a las herramientas básicas para crear soluciones con computadora.

Tema 1

Lenguajes y paradigmas de programación

Un lenguaje de programación es una forma de comunicarse con la computadora para indicarle qué hacer. Los lenguajes se utilizan para crear software y resolver problemas con instrucciones claras. Existen paradigmas distintos (imperativo, orientado a objetos, funcional, lógico) que organizan de manera diferente la forma de resolver problemas.

  • ¿Qué es un lenguaje de programación?
  • ¿Para qué sirve un lenguaje de programación?
  • Lenguajes compilados e interpretados
  • ¿Qué es un paradigma de programación?
  • Paradigma imperativo
  • Paradigma orientado a objetos
  • Paradigma funcional
  • Paradigma lógico
  • Importancia de elegir un paradigma adecuado
Ejemplo

Python e interpretado; C y C++ suelen compilarse a código máquina. Java combina compilación a bytecode e interpretación en la JVM. El paradigma orientado a objetos (usado en Java, C#, Python) organiza el código en clases y objetos.

Ejercicio

Elige dos lenguajes que conozcas (o investiga dos) y escribe un párrafo comparando si son compilados o interpretados y a qué paradigma se asocian principalmente.

Tema 2

Introducción a la programación en Python

Python es un lenguaje de programación muy usado porque es claro, práctico y fácil de aprender. Permite crear programas simples y complejos. Se caracteriza por una sintaxis legible, tipado dinámico y una amplia biblioteca estándar.

  • ¿Qué es Python?
  • Características principales
  • Instalación de Python
  • Estructura básica de un programa
  • La función print()
  • Variables
  • Entrada de datos con input()
  • Tipos de datos básicos
  • Primer programa en Python
Ejemplo
print("Hola Mundo") nombre = "Josue" print("Hola", nombre) edad = int(input("¿Cuántos años tienes? ")) print("Tienes", edad, "años")
Ejercicio

Usa input(), int() y print().

Tema 3

Operadores algebraicos, relacionales y lógicos

Los operadores permiten hacer cálculos, comparar valores y controlar decisiones dentro de un programa. Son fundamentales para producir resultados y tomar decisiones (por ejemplo con if).

  • Operadores algebraicos: suma, resta, multiplicación, división, división entera, módulo y potencia
  • Operadores relacionales: igual que, diferente de, mayor que, menor que, mayor o igual y menor o igual
  • Operadores lógicos: AND, OR y NOT
  • Aplicación de operadores en programas
  • Importancia para la toma de decisiones
Ejemplo
edad = 18 if edad >= 18: print("Mayor de edad") else: print("Menor de edad") usuario = True clave = True if usuario and clave: print("Acceso permitido")
Ejercicio

Escribe un programa que pida dos números y muestre:

a) Su suma, resta, producto y división
b) Si el primero es mayor, menor o igual que el segundo
c) Un mensaje de “ambos positivos” solo si los dos son mayores que cero (usa and)
