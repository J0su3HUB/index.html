Unidad 1: Estructura y funcionamiento del computador

Fundamentos de computación

En esta unidad conoceremos cómo funciona un computador desde sus componentes principales hasta la forma en que procesa la información. Comprender estos conceptos permite desarrollar programas de manera más eficiente, ya que un programador necesita entender cómo piensa y trabaja una computadora antes de escribir código.

Objetivo: comprender la estructura básica del computador y los principios que permiten que el software se ejecute correctamente.

Tema 1

Modelo de Von Neumann y Harvard

La arquitectura de un computador es la forma en que sus partes se organizan para trabajar juntas. El modelo de Von Neumann usa una memoria compartida para guardar datos e instrucciones y una CPU para procesarlos. El modelo Harvard separa la memoria de datos y la memoria de instrucciones para mejorar la velocidad.

  • ¿Qué es la arquitectura de un computador?
  • Modelo de Von Neumann
  • Modelo Harvard
  • Diferencias entre ambos modelos
  • Ventajas y desventajas
  • Aplicaciones actuales
Ejemplo

La mayoría de las computadoras personales actuales siguen una arquitectura inspirada en Von Neumann: un solo bus y una memoria principal donde conviven programa y datos. En cambio, muchos microcontroladores y DSP usan Harvard para ejecutar instrucciones mientras leen datos en paralelo.

Tema 2

Sistemas Operativos

Un sistema operativo es el programa principal que permite que el computador se comunique con el usuario y con los dispositivos. Organiza tareas, controla procesos, administra memoria y facilita el acceso a los archivos.

  • ¿Qué es un sistema operativo?
  • Funciones principales
  • Administración de memoria
  • Administración de procesos
  • Gestión de archivos
  • Tipos de sistemas operativos
  • Ejemplos: Windows, Linux, macOS y Android
Ejemplo

Cuando abres un navegador y un editor de texto a la vez, el sistema operativo reparte el tiempo de CPU entre ambos procesos y asigna memoria a cada uno para que no interfieran entre sí.

Tema 3

Sistemas de Numeración y Conversiones

Los computadores trabajan con números. Los principales sistemas son decimal, binario, octal y hexadecimal. El sistema binario es especialmente importante porque los circuitos digitales interpretan información en dos estados: encendido (1) y apagado (0).

  • Sistema Decimal
  • Sistema Binario
  • Sistema Octal
  • Sistema Hexadecimal
  • Conversión de Decimal a Binario
  • Conversión de Binario a Decimal
  • Conversión entre Binario, Octal y Hexadecimal
  • Importancia en la informática
Ejemplo

Conversión de 25 decimal a binario (divisiones sucesivas entre 2):

25 ÷ 2 = 12 resto 1 12 ÷ 2 = 6 resto 0 6 ÷ 2 = 3 resto 0 3 ÷ 2 = 1 resto 1 1 ÷ 2 = 0 resto 1 Resultado (de abajo hacia arriba): 11001₂

Muestra el procedimiento de divisiones o de potencias de 2.

Tema 4

Aritmética Binaria

La aritmética binaria es el conjunto de operaciones matemáticas que se realizan usando solamente 0 y 1. Es fundamental porque la computadora procesa datos de forma binaria y necesita reglas claras para sumar, restar, multiplicar y dividir.

  • Suma binaria
  • Resta binaria
  • Multiplicación binaria
  • División binaria
  • Reglas básicas
Ejemplo — Suma binaria
1010 + 0110 ------ 10000 Reglas: 0+0=0 · 0+1=1 · 1+1=0 (lleva 1) · 1+1+1=1 (lleva 1)

Tema 5

Álgebra de Boole

El álgebra booleana trabaja con variables que toman dos valores: verdadero o falso (1 o 0). Con estos valores se construyen las decisiones que controlan los circuitos digitales y los programas lógicos.

  • Variables booleanas
  • Valores verdadero y falso
  • Operador AND
  • Operador OR
  • Operador NOT
  • Tablas de verdad
  • Leyes básicas
  • Aplicación en circuitos digitales
Ejemplo
A = 1 B = 0 A AND B = 0 A OR B = 1 NOT A = 0
