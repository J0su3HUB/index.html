Unidad 2: Algoritmos y modelado de problemas

Pensamiento computacional

En esta unidad aprenderemos cómo resolver problemas utilizando el pensamiento lógico. Antes de escribir un programa es importante analizar el problema, planificar una solución y representarla mediante herramientas como algoritmos, diagramas de flujo y pseudocódigo.

Objetivo: aprender a transformar un problema en una solución estructurada, comprensible y aplicable a la programación.

Tema 1

Algoritmos y sus características

Un algoritmo es una secuencia ordenada de pasos que permite resolver un problema o realizar una tarea. Describe cómo debe ejecutarse una solución y es la base de todo programa.

  • ¿Qué es un algoritmo?
  • ¿Para qué sirve un algoritmo?
  • Características de un algoritmo
  • Entrada · Proceso · Salida
  • Algoritmos cotidianos
  • Importancia de los algoritmos en la programación
Ejemplo — Preparar café

1. Calentar agua
2. Colocar el café en la taza
3. Agregar el agua caliente
4. Remover y servir

Ejercicio

Escribe un algoritmo (entre 5 y 8 pasos) para calcular el promedio de tres calificaciones. Identifica claramente la entrada, el proceso y la salida.

Tema 2

Diagramas de flujo

Un diagrama de flujo es una representación gráfica del algoritmo. Permite visualizar el recorrido de una solución usando símbolos estándar: inicio/fin (óvalo), proceso (rectángulo), decisión (rombo), entrada/salida y conectores.

  • ¿Qué es un diagrama de flujo?
  • Símbolos principales
  • Inicio y fin
  • Proceso
  • Entrada y salida de datos
  • Decisiones
  • Conectores
  • Ventajas de utilizar diagramas de flujo
Ejemplo

Para saber si un número es par o impar: se lee el número, se calcula el residuo al dividir entre 2; si el residuo es 0 se muestra “par”, en caso contrario “impar”. El rombo representa esa decisión.

Ejercicio

Dibuja un diagrama de flujo que determine si una persona es mayor de edad (edad ≥ 18). Usa al menos los símbolos de inicio, entrada, decisión, proceso/salida y fin.

Tema 3

Pseudocódigo

El pseudocódigo es una forma de escribir una solución usando palabras y estructuras simples, sin depender de la sintaxis de un lenguaje de programación específico. Sirve para planificar antes de codificar.

  • ¿Qué es el pseudocódigo?
  • ¿Para qué sirve?
  • Reglas básicas
  • Variables
  • Entrada de datos
  • Procesos
  • Salida de resultados
  • Diferencias entre pseudocódigo y lenguaje de programación
Ejemplo
Inicio Leer A Leer B Resultado ← A + B Escribir Resultado Fin
Ejercicio

Escribe en pseudocódigo el algoritmo para calcular el área de un triángulo (base × altura / 2). Incluye lectura de base y altura, el cálculo y la escritura del resultado.

Tema 4

Modelado de problemas

Antes de programar es necesario entender el problema. El modelado ayuda a reconocer las entradas, los procesos y las salidas, y a diseñar una solución clara y ordenada.

  • ¿Qué es un problema?
  • Identificación del problema
  • Análisis de datos
  • Entradas
  • Procesos
  • Salidas
  • Diseño de una solución
  • Importancia del modelado antes de programar
Ejemplo — Promedio de tres calificaciones

Entradas: nota1, nota2, nota3
Proceso: promedio = (nota1 + nota2 + nota3) / 3
Salida: mostrar el promedio

Ejercicio

Modela el siguiente problema: “Calcular el total a pagar de una compra con descuento del 10% si el monto supera $50”. Identifica entradas, proceso (con la condición) y salida.
